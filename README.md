# dotfiles

My Mac settings files: zsh config, oh-my-zsh custom plugins and theme, VS Code settings, Obsidian style settings, and default-app rules for `duti`.

## Use

Nothing installs these for you. Copy or symlink a file to where it belongs, for example:

```bash
ln -s ~/Personal/code/dotfiles/.zshrc ~/.zshrc
```

`oh-my-zsh-custom/` is meant for `~/.oh-my-zsh/custom`. The `.zshrc` uses oh-my-zsh, so install that first.
